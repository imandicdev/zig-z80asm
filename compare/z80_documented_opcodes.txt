================================================================================
 FLAGS REFERENCE
================================================================================

 S = Sign (bit 7 of result)
 Z = Zero (result is zero)
 H = Half-carry (carry from bit 3)
 V = Overflow/Parity (P/V flag)
 N = Subtract (set if last op was subtraction)
 C = Carry (carry from bit 7)

 Flag notation:
   S  = affected
   -  = not affected
   *  = special behavior (see Zilog manual)
   0  = reset
   1  = set
